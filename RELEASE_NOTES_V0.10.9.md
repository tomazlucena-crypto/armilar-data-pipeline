# ARMILAR v0.10.9

## ECOICOP transition backtest execution engine

This release defines the deterministic execution-result contract for the ECOICOP v1/v2 transition backtest.

The milestone validates the execution engine against a fixture readiness report produced through v0.10.8. It does not claim that an empirical transition backtest has been run on a real verified external panel.
