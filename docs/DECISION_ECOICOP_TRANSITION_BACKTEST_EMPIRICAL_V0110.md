# Decision: ECOICOP transition empirical backtest gate v0.11.0

The project must not claim a real transition backtest merely because a fixture execution engine exists. v0.11.0 therefore introduces a fail-closed empirical gatekeeper.

The gatekeeper requires an external verified dual-panel attachment and an external empirical result artifact before any future execution claim can be considered. In this repository PR it only produces a preflight report explaining why empirical execution remains blocked.

No constitutional decision is made. No strategy is selected. No ARM-O 2026 extension is authorized.
