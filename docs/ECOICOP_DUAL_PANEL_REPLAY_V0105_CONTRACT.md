# ECOICOP dual-panel replay verifier v0.10.5

## Objective

Define the offline verifier for a future external ECOICOP v1/v2 dual-panel
artifact.  The verifier is a precondition for the empirical transition backtest.
It does not itself acquire live data, commit official bytes or verify a real
panel.

## Inputs

- `config/ecoicop_dual_panel_v0104.json`;
- `config/ecoicop_dual_panel_replay_v0105.json`;
- external artifact directory generated by a non-PR acquisition run.

## Required external artifact

A real artifact must contain:

```text
PANEL_MANIFEST.sha256
panel_summary.json
raw_receipts.csv
normalised_observations.csv
dual_panel_coverage.csv
dual_panel_lineage.csv
```

The manifest must hash every committed artifact file.  Raw paths must be safe
relative paths inside the artifact directory.  Every normalised observation must
link to a raw receipt.  Every observed coverage row must link to an observation.
Every lineage row must link to both the observation and receipt and must declare
`may_rewrite_history=false`.

## Invariants

- no official bytes are committed in this code PR;
- no `public/latest` file is changed;
- no live 2026 observation is accepted;
- no transition strategy is selected;
- no backtest is executed;
- no gate is opened;
- missing coverage must be explicit, not silently imputed.

## Success condition

The contract scaffold is reproducible, the checker validates the v0.10.4
predecessor and the fixture-level external artifact verifier accepts and rejects
artifacts according to the declared rules.
