# Decision: v0.11.1 external dual-panel intake

The project now has enough contractual machinery to admit a real external panel
without confusing the admission of data with the economic backtest.  The intake
report confirms that a verified external panel is available, but still refuses
to claim a backtest, interpret results, select a strategy, or open gates.

This avoids another round of abstract scaffolding while preserving the rule that
large official data artifacts are not committed to the source repository.
