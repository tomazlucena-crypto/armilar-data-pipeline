# ARMILAR v0.10.7

## ECOICOP v1/v2 external dual-panel attachment protocol

This release defines the deterministic protocol for attaching a materialized
external ECOICOP v1/v2 dual-panel artifact to an auditable descriptor.

The release does **not** acquire live provider bytes, does not commit official
bytes, does not change `public/latest`, does not execute the transition
backtest, does not select T0/T1/T2/T3, and does not ratify the ECOICOP
transition.
